# 新风滤网压差复标数据与算法

导入自备批次或复核估计时阅读。先核对下面的字段和时间窗。查看隔离行原因，再核对估计和派发结果。

## 单据

| 字段 | 用途 | 单位 | 有效区间 |
|---|---|---|---|
| `pressure_pa` | 滤网压差 | Pa | 14–340 |
| `fan_pct` | 风机档位 | % | 18–95 |
| `flow_cmh` | 供风量 | m³/h | 180–3600 |
| `pm_index` | 外部颗粒计数 | 个/L | 3–250 |
| `open_pct` | 回风阀开度 | % | 5–95 |
| `since_days` | 换网后使用 | 天 | 3–185 |

`key` 是单号，`cohort` 是作业区，文本先做 NFKC 归一化。`day` 为测量工日，`received` 为到站工日，`revision` 为正整数版次。同版记录出现多个不同测量结果时隔离该单全部版次。缺测可空置，但每条单至少包含四项观测。

`outcome` 与 `result_day` 成对填写。标签 0 为已核实正常，1 为需要复核的实绩。 `observed` 省略时为 `true`，只在留架右截尾场景允许 `false`。

### 原始行业单据

允许使用 `form` 对象代替平铺量测。保留单号、版次、工日和标签等顶层字段。表中的换算为 `(单据值 − 原点偏移) / 倍率`。每行内部校验完成后，与平铺数据使用同一分窗、建模和派单过程。

| 单据组 | 原始字段 | 用途 | 倍率 | 原点偏移 |
|---|---|---|---:|---:|
| 机组本体 | `delta_millipascal` | 压差毫帕 | 1000 | 0 |
| 机组本体 | `fan_basis_points` | 风机万分档 | 100 | 0 |
| 回风抄读 | `supply_m3h` | 小时立方米 | 1 | 0 |
| 回风抄读 | `outside_particle_litre` | 每升室外粒数 | 1 | 0 |
| 滤网登记 | `return_basis_points` | 回气阀万分档 | 100 | 0 |
| 滤网登记 | `filter_running_hours` | 自换芯小时 | 24 | 0 |

示例见 `sample_data/duct_checklists_form.json`。混合使用两种量测表示，或单据内读数互相矛盾时，保留隔离原因。

## 时序与训练

拟合 `[0,40)`、校准 `[42,62)`、回放 `[65,85)`、当班从 `88` 日起。前三个窗口的入站和结果都须早于窗口终点。到站日晚于截止日的单据在入站隔离。拟合期冻结补值中位数、均值、尺度及训练包络。

| 特征 | 语义 | 公式 |
|---|---|---|
| `flow_resistance` | 流量校正阻力 | `pressure_pa/(1+flow_cmh**2/1e6)` |
| `fan_delivery` | 转速归一风量 | `flow_cmh/(fan_pct+5)` |
| `particle_load` | 积尘暴露 | `pm_index*since_days/100` |
| `return_factor` | 回风供风比 | `open_pct/(fan_pct+10)` |
| `resistance_age` | 压差与使用期比例 | `pressure_pa/(1+since_days/25)` |

### PCA 压差残差评分

用常态机组的 SVD 前两主成分恢复共同变化，将剩余偏差按各项稳健尺度统一后合成异常分。

本工作台的独立样本校准方式为风阻子空间单调分箱。风险校准无法确认正负样本时转人工判读。连续估计使用独立校准残差计算双侧区间，误差尺度随作业条件变化。分布监测对训练和当班量测比较分区累积分布差。未知作业区、两项缺测或两项明显超训练包络的单据需要人工判读。

## 分配滤网复标

| 优先级 | 原因码 | 条件 | 处置依据 |
|---:|---|---|---|
| 1 | `FILTER_DIFFERENTIAL` | `pressure_pa >= 275 and flow_cmh <= 1200` | 现场复核滤网压差 |
| 2 | `EXHAUST_IMBALANCE` | `fan_pct >= 76 and open_pct <= 25` | 同时核对回风阀反馈 |
| 3 | `SERVICE_INTERVAL` | `since_days >= 140 and pm_index > 125` | 过滤介质超观察窗口 |

第一条为暂停规则。其余命中与模型阈值 `0.6` 共同决定是否列入候选。单据所需工位数按 `1 + int(flow_cmh > 1450)` 计算。均衡策略对分区限额，集中复核策略允许把额度集中投入高风险区。未分派原因在导出的处置记录中保留。签发前核对每张当班单和工位余额。

### 标准档复标单

将压差和风量换算至风机 65% 档作经验对照，再按阻力比和回风反馈区分测压、换网和阀位复核。班组须在实际档位重取稳态记录。 在派发环节展开现场安排，或从关联单据回查实际读数。
